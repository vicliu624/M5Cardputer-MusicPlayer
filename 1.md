# 音频解码器实现方案

## 概述

ES8311 只能播放 PCM 数据，因此需要将 MP3/WAV/FLAC 文件解码为 PCM 格式。本文档提供针对 ESP32-S3 (8MB Flash, 无 PSRAM) 的音频解码实现方案。

## 格式分析

### 1. WAV 文件
- **特点**：通常包含未压缩的 PCM 数据
- **解码难度**：⭐ 简单
- **内存需求**：低（只需解析 WAV 头）
- **实现方式**：解析 WAV 头，直接提取 PCM 数据

### 2. MP3 文件
- **特点**：压缩格式，需要解码
- **解码难度**：⭐⭐⭐ 中等
- **内存需求**：中等（约 2-4KB 解码缓冲区）
- **实现方式**：使用轻量级 MP3 解码库

### 3. FLAC 文件
- **特点**：无损压缩，解码复杂度高
- **解码难度**：⭐⭐⭐⭐ 较难
- **内存需求**：较高（约 8-16KB 解码缓冲区）
- **实现方式**：使用 libFLAC 或简化实现

## 推荐方案

### 方案 1：轻量级方案（推荐）⭐

**支持格式**：WAV + MP3

**解码库选择**：
- **MP3**: [minimp3](https://github.com/lieff/minimp3) - 单文件头，约 2KB Flash
- **WAV**: 自实现解析器 - 约 1KB Flash

**优点**：
- ✅ 内存占用小（解码缓冲区 2-4KB）
- ✅ Flash 占用小（总计约 3KB）
- ✅ 解码速度快
- ✅ 适合流式解码

**缺点**：
- ❌ 不支持 FLAC
- ❌ MP3 仅支持标准格式（不支持 VBR 等高级特性）

### 方案 2：完整方案

**支持格式**：WAV + MP3 + FLAC

**解码库选择**：
- **MP3**: minimp3
- **WAV**: 自实现
- **FLAC**: [libFLAC](https://github.com/xiph/flac) 或 [FLAC Embedded](https://github.com/richardghirst/flac-embedded)

**优点**：
- ✅ 支持所有常见格式
- ✅ FLAC 无损音质

**缺点**：
- ❌ 内存占用较大（FLAC 解码需要 8-16KB）
- ❌ Flash 占用大（FLAC 库约 20-30KB）
- ❌ 可能超出内存限制

## 实现架构

### 统一解码接口

```cpp
// main/apps/utils/audio_decoder/audio_decoder.h
#pragma once

#include <cstdint>
#include <cstddef>
#include <string>

namespace audio_decoder {

enum class Format {
    UNKNOWN,
    WAV,
    MP3,
    FLAC
};

struct AudioInfo {
    uint32_t sample_rate;    // 采样率 (Hz)
    uint16_t channels;       // 声道数 (1=单声道, 2=立体声)
    uint16_t bits_per_sample; // 位深 (16, 24, 32)
    size_t total_samples;    // 总采样点数（如果已知）
};

class AudioDecoder {
public:
    virtual ~AudioDecoder() = default;
    
    // 打开音频文件/流
    virtual bool open(const uint8_t* data, size_t size) = 0;
    virtual bool open(const std::string& filepath) = 0;
    
    // 获取音频信息
    virtual bool getInfo(AudioInfo& info) = 0;
    
    // 解码音频数据
    // 返回解码的采样点数（不是字节数）
    virtual size_t decode(int16_t* pcm_buffer, size_t max_samples) = 0;
    
    // 重置解码器（用于重新播放）
    virtual bool reset() = 0;
    
    // 关闭解码器
    virtual void close() = 0;
    
    // 检查是否还有数据
    virtual bool hasMore() const = 0;
    
    // 获取当前解码位置（采样点数）
    virtual size_t getPosition() const = 0;
    
    // 跳转到指定位置（采样点数）
    virtual bool seek(size_t position) = 0;
};

// 工厂函数：根据文件扩展名或数据头创建解码器
AudioDecoder* createDecoder(Format format);
Format detectFormat(const uint8_t* data, size_t size);
Format detectFormat(const std::string& filepath);

} // namespace audio_decoder
```

```cpp
// main/apps/utils/audio_decoder/wav_decoder.cpp
#include "wav_decoder.h"
#include <cstring>
#include <algorithm>

namespace audio_decoder {

bool WavDecoder::parseHeader() {
    if (_data_size < sizeof(WavHeader)) {
        return false;
    }
    
    const WavHeader* header = reinterpret_cast<const WavHeader*>(_data);
    
    // 检查 RIFF 和 WAVE 标识
    if (memcmp(header->riff, "RIFF", 4) != 0 ||
        memcmp(header->wave, "WAVE", 4) != 0) {
        return false;
    }
    
    // 检查格式（只支持 PCM）
    if (header->audio_format != 1) {
        return false; // 不支持非 PCM 格式
    }
    
    // 检查位深（只支持 16-bit）
    if (header->bits_per_sample != 16) {
        return false; // 只支持 16-bit
    }
    
    // 填充音频信息
    _info.sample_rate = header->sample_rate;
    _info.channels = header->channels;
    _info.bits_per_sample = header->bits_per_sample;
    
    // 查找 data chunk
    size_t offset = sizeof(WavHeader);
    while (offset + 8 < _data_size) {
        const char* chunk_id = reinterpret_cast<const char*>(_data + offset);
        uint32_t chunk_size = *reinterpret_cast<const uint32_t*>(_data + offset + 4);
        
        if (memcmp(chunk_id, "data", 4) == 0) {
            _data_offset = offset + 8;
            _info.total_samples = chunk_size / (header->channels * 2); // 16-bit = 2 bytes
            return true;
        }
        
        offset += 8 + chunk_size;
        if (chunk_size % 2) offset++; // 对齐到偶数字节
    }
    
    return false;
}

bool WavDecoder::open(const uint8_t* data, size_t size) {
    close();
    _data = data;
    _data_size = size;
    _current_pos = 0;
    
    if (!parseHeader()) {
        return false;
    }
    
    _current_pos = _data_offset;
    _is_open = true;
    return true;
}

size_t WavDecoder::decode(int16_t* pcm_buffer, size_t max_samples) {
    if (!_is_open || !hasMore()) {
        return 0;
    }
    
    size_t bytes_available = _data_size - _current_pos;
    size_t samples_available = bytes_available / (_info.channels * 2); // 16-bit = 2 bytes
    size_t samples_to_decode = std::min(max_samples, samples_available);
    size_t bytes_to_copy = samples_to_decode * _info.channels * 2;
    
    memcpy(pcm_buffer, _data + _current_pos, bytes_to_copy);
    _current_pos += bytes_to_copy;
    
    return samples_to_decode;
}

bool WavDecoder::reset() {
    if (!_is_open) return false;
    _current_pos = _data_offset;
    return true;
}

void WavDecoder::close() {
    _data = nullptr;
    _data_size = 0;
    _data_offset = 0;
    _current_pos = 0;
    _is_open = false;
}

bool WavDecoder::hasMore() const {
    if (!_is_open) return false;
    return _current_pos < _data_size;
}

size_t WavDecoder::getPosition() const {
    if (!_is_open) return 0;
    size_t bytes_decoded = _current_pos - _data_offset;
    return bytes_decoded / (_info.channels * 2);
}

bool WavDecoder::seek(size_t position) {
    if (!_is_open) return false;
    size_t byte_position = _data_offset + position * _info.channels * 2;
    if (byte_position > _data_size) return false;
    _current_pos = byte_position;
    return true;
}

} // namespace audio_decoder
```

```cpp
// main/apps/utils/audio_decoder/mp3_decoder.cpp
#include "mp3_decoder.h"
#include <cstring>
#include <algorithm>

namespace audio_decoder {

Mp3Decoder::Mp3Decoder() {
    mp3dec_init(&_mp3d);
    _decode_buffer.resize(MP3_MAX_SAMPLES_PER_FRAME * 2); // 立体声最大帧
}

Mp3Decoder::~Mp3Decoder() {
    close();
}

bool Mp3Decoder::parseInfo() {
    if (_info_parsed) return true;
    if (!_is_open) return false;
    
    // 解码第一帧以获取信息
    size_t saved_pos = _current_pos;
    _current_pos = 0;
    
    int samples = mp3dec_decode_frame(&_mp3d, _data, _data_size, 
                                      _decode_buffer.data(), &_frame_info);
    
    if (samples > 0 && _frame_info.bitrate_kbps > 0) {
        _info.sample_rate = _frame_info.hz;
        _info.channels = _frame_info.channels;
        _info.bits_per_sample = 16;
        _info.total_samples = 0; // MP3 总长度未知
        _info_parsed = true;
        _current_pos = saved_pos;
        return true;
    }
    
    _current_pos = saved_pos;
    return false;
}

bool Mp3Decoder::open(const uint8_t* data, size_t size) {
    close();
    _data = data;
    _data_size = size;
    _current_pos = 0;
    _info_parsed = false;
    
    if (!parseInfo()) {
        return false;
    }
    
    _is_open = true;
    return true;
}

size_t Mp3Decoder::decode(int16_t* pcm_buffer, size_t max_samples) {
    if (!_is_open || !hasMore()) {
        return 0;
    }
    
    size_t total_decoded = 0;
    
    while (total_decoded < max_samples && hasMore()) {
        // 解码一帧
        int samples = mp3dec_decode_frame(&_mp3d, 
                                          _data + _current_pos, 
                                          _data_size - _current_pos,
                                          _decode_buffer.data(), 
                                          &_frame_info);
        
        if (samples <= 0) {
            break; // 解码完成或错误
        }
        
        // 更新位置
        _current_pos += _frame_info.frame_bytes;
        
        // 复制解码数据
        size_t samples_to_copy = std::min(static_cast<size_t>(samples * _frame_info.channels),
                                          max_samples - total_decoded);
        
        memcpy(pcm_buffer + total_decoded, 
               _decode_buffer.data(), 
               samples_to_copy * sizeof(int16_t));
        
        total_decoded += samples_to_copy;
        
        if (samples_to_copy < static_cast<size_t>(samples * _frame_info.channels)) {
            break; // 缓冲区已满
        }
    }
    
    return total_decoded;
}

bool Mp3Decoder::reset() {
    if (!_is_open) return false;
    mp3dec_init(&_mp3d);
    _current_pos = 0;
    return true;
}

void Mp3Decoder::close() {
    _data = nullptr;
    _data_size = 0;
    _current_pos = 0;
    _is_open = false;
    _info_parsed = false;
}

bool Mp3Decoder::hasMore() const {
    if (!_is_open) return false;
    return _current_pos < _data_size;
}

size_t Mp3Decoder::getPosition() const {
    // MP3 无法精确计算位置，返回近似值
    return 0; // TODO: 实现近似计算
}

bool Mp3Decoder::seek(size_t position) {
    // MP3 不支持精确跳转，只能重置
    return reset();
}

} // namespace audio_decoder
```

### 3. 格式检测

```cpp
// main/apps/utils/audio_decoder/format_detector.cpp
#include "audio_decoder.h"
#include <cstring>
#include <algorithm>

namespace audio_decoder {

Format detectFormat(const uint8_t* data, size_t size) {
    if (size < 12) return Format::UNKNOWN;
    
    // 检测 WAV
    if (size >= 12 && 
        memcmp(data, "RIFF", 4) == 0 &&
        memcmp(data + 8, "WAVE", 4) == 0) {
        return Format::WAV;
    }
    
    // 检测 MP3 (ID3v2 或 MP3 帧同步)
    if (size >= 3) {
        // ID3v2 标签
        if (memcmp(data, "ID3", 3) == 0) {
            return Format::MP3;
        }
        // MP3 帧同步 (0xFF 0xFB/0xFA/0xF2/0xF3)
        if (data[0] == 0xFF && (data[1] & 0xE0) == 0xE0) {
            return Format::MP3;
        }
    }
    
    // 检测 FLAC
    if (size >= 4 && memcmp(data, "fLaC", 4) == 0) {
        return Format::FLAC;
    }
    
    return Format::UNKNOWN;
}

Format detectFormat(const std::string& filepath) {
    // 根据文件扩展名检测
    size_t dot_pos = filepath.find_last_of('.');
    if (dot_pos == std::string::npos) {
        return Format::UNKNOWN;
    }
    
    std::string ext = filepath.substr(dot_pos + 1);
    std::transform(ext.begin(), ext.end(), ext.begin(), ::tolower);
    
    if (ext == "wav") return Format::WAV;
    if (ext == "mp3") return Format::MP3;
    if (ext == "flac") return Format::FLAC;
    
    return Format::UNKNOWN;
}

AudioDecoder* createDecoder(Format format) {
    switch (format) {
        case Format::WAV:
            return new WavDecoder();
        case Format::MP3:
            return new Mp3Decoder();
        case Format::FLAC:
            // return new FlacDecoder(); // 如果实现了 FLAC
            return nullptr;
        default:
            return nullptr;
    }
}

} // namespace audio_decoder
```

## 使用示例

### 示例 1：播放本地文件

```cpp
#include "apps/utils/audio_decoder/audio_decoder.h"

void playAudioFile(const std::string& filepath) {
    // 检测格式
    auto format = audio_decoder::detectFormat(filepath);
    if (format == audio_decoder::Format::UNKNOWN) {
        mclog::tagError("Audio", "Unsupported format");
        return;
    }
    
    // 创建解码器
    auto decoder = audio_decoder::createDecoder(format);
    if (!decoder) {
        mclog::tagError("Audio", "Failed to create decoder");
        return;
    }
    
    // 打开文件（需要实现文件读取）
    // 这里假设有 readFile 函数
    std::vector<uint8_t> file_data = readFile(filepath);
    if (!decoder->open(file_data.data(), file_data.size())) {
        mclog::tagError("Audio", "Failed to open file");
        delete decoder;
        return;
    }
    
    // 获取音频信息
    audio_decoder::AudioInfo info;
    if (!decoder->getInfo(info)) {
        mclog::tagError("Audio", "Failed to get audio info");
        decoder->close();
        delete decoder;
        return;
    }
    
    mclog::tagInfo("Audio", "Sample rate: {} Hz, Channels: {}, Bits: {}",
                   info.sample_rate, info.channels, info.bits_per_sample);
    
    // 初始化扬声器
    GetHAL().speaker.begin();
    GetHAL().speaker.setVolume(255);
    
    // 解码并播放
    constexpr size_t BUFFER_SIZE = 1024; // 1024 个采样点
    std::vector<int16_t> pcm_buffer(BUFFER_SIZE * info.channels);
    
    while (decoder->hasMore()) {
        size_t samples = decoder->decode(pcm_buffer.data(), BUFFER_SIZE);
        if (samples == 0) break;
        
        // 转换为单声道（如果需要）
        if (info.channels == 2) {
            // 混合立体声为单声道
            std::vector<int16_t> mono_buffer(samples);
            for (size_t i = 0; i < samples; ++i) {
                mono_buffer[i] = (pcm_buffer[i * 2] + pcm_buffer[i * 2 + 1]) / 2;
            }
            GetHAL().speaker.playRaw(mono_buffer.data(), samples, 
                                     info.sample_rate, false);
        } else {
            GetHAL().speaker.playRaw(pcm_buffer.data(), samples, 
                                     info.sample_rate, false);
        }
        
        // 等待播放完成
        while (GetHAL().speaker.isPlaying()) {
            GetHAL().delay(1);
        }
    }
    
    decoder->close();
    delete decoder;
}
```

## 内存占用估算

### 方案 1（WAV + MP3）

| 组件 | Flash | RAM |
|------|-------|-----|
| minimp3 库 | ~2KB | ~1KB |
| WAV 解析器 | ~1KB | ~0.5KB |
| 解码缓冲区 | 0 | 2-4KB |
| PCM 播放缓冲区 | 0 | 2-4KB |
| **总计** | **~3KB** | **~6-10KB** |

### 方案 2（WAV + MP3 + FLAC）

| 组件 | Flash | RAM |
|------|-------|-----|
| minimp3 库 | ~2KB | ~1KB |
| WAV 解析器 | ~1KB | ~0.5KB |
| FLAC 库 | ~25KB | ~8KB |
| 解码缓冲区 | 0 | 8-16KB |
| PCM 播放缓冲区 | 0 | 2-4KB |
| **总计** | **~28KB** | **~20-30KB** |

## 推荐实施步骤

1. **第一阶段**：实现 WAV 解码器
   - ✅ 简单，可以快速验证架构
   - ✅ 测试播放流程

2. **第二阶段**：添加 MP3 支持
   - ✅ 集成 minimp3
   - ✅ 实现 MP3 解码器
   - ✅ 测试流式解码

3. **第三阶段**（可选）：添加 FLAC 支持
   - ⚠️ 评估内存是否足够
   - ⚠️ 如果内存紧张，可以跳过

## 总结

**推荐方案**：**方案 1（WAV + MP3）**

- ✅ 满足大部分使用场景
- ✅ 内存占用小，适合 ESP32-S3
- ✅ 实现简单，维护成本低
- ✅ 支持流式解码，适合 WiFi 播放

**如果必须支持 FLAC**：
- 考虑使用更轻量的 FLAC 实现
- 或者限制 FLAC 文件的最大采样率和位深
- 或者使用服务器端转码（将 FLAC 转为 MP3）
